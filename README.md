# SkyPulse Weather Dashboard — Web Development Week 3

## 📌 Project Overview
This repository contains the **Week 3 Web Development Assignment**. The project is a modern, responsive **Weather Web Application** built using **HTML5**, **Tailwind CSS**, and **JavaScript** (`Fetch API`, `async/await`, and `JSON` parsing).

---

## 🛠️ Assignment Objectives & Features
* **Asynchronous Fetch API**: Uses `fetch()` with `async/await` to retrieve real-time weather metrics from live APIs.
* **JSON Parsing & Manipulation**: Extracts city coordinates, temperatures, conditions, humidity, wind speeds, and pressure metrics from API responses.
* **City Search & Quick Chips**: Interactive search input field along with quick-selection chips for popular global cities (London, Tokyo, New York, Mumbai, Paris).
* **Unit Conversion Toggle**: Smooth dynamic switching between Celsius (°C) and Fahrenheit (°F).
* **5-Day Weather Forecast**: Displays daily weather forecasts with corresponding dynamic icons.
* **Graceful Exception Handling**: Features custom loading state animations, invalid city alerts, and automated offline fallback simulation modes.
